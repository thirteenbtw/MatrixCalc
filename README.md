# MatrixCalculator

Консольный калькулятор матриц на C++20.

## Возможности

- сложение и вычитание матриц
- умножение матриц
- умножение матрицы на число
- транспонирование
- определитель

Ввод проверяется: при ошибке программа просит повторить, а несовместимые размеры матриц дают понятное сообщение.

## Структура

- `core/` — библиотека с классом `Matrix`
- `app/` — консольное приложение (меню и ввод)
- `tests/` — тесты на Catch2 (скачивается автоматически)

## Сборка

Нужны CMake 4.3+ и компилятор с поддержкой C++20.

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

```bash
./build/app/app        # на Windows: build\app\app.exe
```

## Тесты

```bash
./build/tests/tests    # на Windows: build\tests\tests.exe
```
