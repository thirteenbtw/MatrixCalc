# MatrixCalculator

Калькулятор матриц, векторов и систем линейных уравнений на C++20.
Два интерфейса в одном файле: окно с кнопками и консольное меню.

## Возможности

**Матрицы:** сложение, вычитание, умножение, умножение на число, транспонирование, определитель, ранг.

**Векторы:** сложение, вычитание, умножение на число, длина, скалярное, векторное и смешанное произведение, угол между векторами.

**СЛАУ:** решение методом Гаусса (единственное решение, общее решение при бесконечном множестве, «решений нет»).

Числа вводятся обыкновенными дробями (`1/3`, `-7/2`) или десятичными (`0.5`), все вычисления точные.

## Запуск

```bash
app              # графический интерфейс (окно)
app --console    # консольное меню
app --help       # справка
```

Готовые файлы для Windows, macOS и Linux лежат в разделе Releases.

## Сборка

Нужны CMake 4.3+ и компилятор с поддержкой C++20. Библиотеки для окна (GLFW и Dear ImGui) скачиваются автоматически.

```bash
cmake -S . -B build
cmake --build build
```

На Linux для окна понадобятся пакеты разработки X11 и OpenGL:

```bash
sudo apt-get install libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libgl1-mesa-dev
```

## Структура

- `core/` — вычисления: `Fraction`, `Matrix`, `Vector`, решатель СЛАУ
- `app/` — приложение: `GuiApp` (окно), `ConsoleApp` (меню в терминале), `main.cpp` (выбор режима)
- `tests/` — тесты на Catch2
